# 坦克大战 Battle City 🎮

经典坦克大战游戏的 HTML/Canvas 实现，纯前端，无需任何依赖。

## 玩法说明

- **目标**: 消灭所有敌方坦克，保护我方基地（金色 ★ 标志）
- **操作**:
  - `W A S D` 或 `方向键` — 移动坦克
  - `空格` 或 `J` — 射击
  - `Enter` — 开始 / 重新开始

## 游戏特性

- 3 条生命，每局 20 辆敌方坦克
- 砖墙可被炮弹摧毁，钢墙不可摧毁
- 敌方坦克具有基础 AI（追击玩家 + 随机移动）
- 关卡系统 — 通关后进入下一关
- 实时得分、生命、关卡、剩余敌人显示

## 如何运行

直接打开 `index.html` 即可游玩，无需服务器或安装任何依赖。
